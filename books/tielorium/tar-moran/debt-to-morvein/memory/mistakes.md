# Mistakes — «Долг перед Морвейн»

Короткие переиспользуемые правила письма для этой книги (не жалобы по конкретной главе). Пополнять по ходу критики/ревизий.

- Магия — переговоры, не приказ: каждая дуэль — сделка с волей мира с видимой ценой, не фехтование.
- Сила Договора — кредит, не дар: не давать побед без утяжеления долга.
- Ярость показывать как двойное лезвие в моменте (мощь + муть резонанса), не объяснением.
- Долг не обнулять и не «прощать» ради сцены — сверяться с `memory-ledger.md`; воплощённое не исчезает само.
- Возвращающихся писать буднично и «по праву», не дешёвыми призраками; ужас — в нормальности неправильного.
- Не описывать разные дуэли одинаково; беречь эскалацию долга и ставок к финалу.
- Не выводить прочие дисциплины Морвейна на первый план; фокус — Договор/Эхо (исключение — Истинный слой Сейлы как зеркало).
- Избегать непобедимости без цены, злодея ради злодейства и deus ex machina, обнуляющего долг.
